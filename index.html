    Aide et raccourcis

    Deux modes

    Expression : les priorités habituelles s’appliquent, 2+3×4 = 14, l’expression reste modifiable.

    Immédiat : façon calculatrice de poche, 2+3×4 = 20, = répété rejoue la dernière opération.

    Conventions

    • , est la virgule décimale ; ; sépare les arguments : log(8;2).
    • % divise par 100 : 200+10% = 200,1.
    • −2^2 = −4, 2^3^2 = 512, 3! = 6, 50% = 0,5.
    • La multiplication implicite est acceptée : 2π, 3(4+5), 2sin(30).
    • Les angles suivent le mode DEG / RAD / GRAD affiché en haut de l’écran.
    • EXP insère ×10^( : 1,23 EXP 5 = 123 000.
